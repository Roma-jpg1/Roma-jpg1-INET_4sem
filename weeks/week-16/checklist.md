# Security Checklist (`tasks-s18`)

## Проверки по OWASP Top 10

1. Аутентификация на `POST /tasks` не пройдено
Факт задачу можно создать без токена

2. Авторизация доступа к ресурсам не пройдено
Факт в текущем сервисе нет механизма auth/authz

3. Проверка на SQL Injection в path/query пройдено
Факт строка вида `1 OR 1=1` режется валидацией и дает `422`

4. Валидация поля `due` не пройдено
Факт значение вроде `<script>alert(1)</script>` принимается

5. Ограничение максимального размера payload не пройдено
Факт очень большой JSON около 200KB проходит с кодом `200`

6. Rate limiting не пройдено
Факт сервис принимает большой поток запросов без ограничений

7. Публичная документация `/docs` в runtime не пройдено
Факт Swagger открыт

8. Утечка stack trace в ответах пройдено
Факт клиент получает обычные структурированные ошибки без трассировок

9. Security headers `HSTS` `X-Frame-Options` `CSP` не пройдено
Факт базовые защитные заголовки не выставляются

10. Корректные HTTP-статусы на ошибках пройдено
Факт ошибки валидации возвращаются как `422`

11. Валидация типа `task_id` в path пройдено
Факт `task_id` строго числовой

12. Секреты в коде пройдено
Факт в `weeks/week-14/service/main.py` явных секретов не найдено
