# Security Audit Report (`tasks-s18`)

## Как проводился аудит
Проверял сервис `tasks-s18` руками как это делает обычный security smoke test
Отправлял разные запросы смотрел коды ответов и поведение API в нестандартных ситуациях

## Подтвержденные наблюдения

1. Отсутствует аутентификация на write операции
Проверка отправка `POST /tasks` без токена
Результат сервер принимает запрос и создает запись с кодом `200`
Риск высокий потому что любой клиент может менять данные

2. Недостаточная валидация данных поля `due`
Проверка отправка значения `<script>alert(1)</script>` в поле `due`
Результат значение принимается код ответа `200`
Риск средний потому что в систему можно записать грязные данные

3. Нет ограничений размера входного тела
Проверка отправка очень большого JSON около 200KB
Результат запрос успешно обрабатывается с кодом `200`
Риск средний высокий так как это упрощает нагрузочные атаки

4. Нет rate limiting
Проверка серия из большого числа запросов с высокой параллельностью
Результат сервис обрабатывает поток без ограничений и без блокировок
Риск средний есть риск flood DoS сценариев

5. Swagger UI открыт публично
Проверка переход на `/docs`
Результат документация открыта и доступна
Риск низкий средний упрощает разведку API

6. Отсутствуют security headers
Проверка анализ заголовков ответа `GET /tasks`
Результат нет базовых защитных заголовков `HSTS` `X-Frame-Options` `X-Content-Type-Options` `CSP`
Риск средний

## Проверки, которые сработали корректно
- Попытка SQL like path injection `GET /tasks/1 OR 1=1` отклоняется с кодом `422`
- Сервис не показывает пользователю stack trace в ответах

## Рекомендации по исправлению
1. Добавить обязательную аутентификацию и авторизацию для всех write endpoint
2. Ввести строгую валидацию `due` формат даты длина whitelist символов
3. Ограничить максимальный размер request body на gateway и в приложении
4. Включить rate limiting per IP per token и burst control
5. Отключить `/docs` и `/openapi.json` в production или закрыть за auth
6. Добавить security headers на ingress gateway

## Итог
Для учебного проекта `tasks-s18` этого достаточно
До production уровня не хватает базовой защиты контроля доступа лимитов и более строгой валидации входных данных
