# Вопросы для самопроверки

1. В чем главное концептуальное отличие GraphQL от REST?

REST — множество эндпоинтов, каждый возвращает фиксированную структуру.
GraphQL — один эндпоинт, клиент сам выбирает поля. Клиент получает ровно то, что запросил 


2. Что такое Schema Definition Language (SDL)?

type User {
  id: ID!
  name: String!
  posts: [Post!]!
}

3. Чем Query отличается от Mutation? Могут ли они выполняться параллельно?

Query — для получения данных (аналог GET). Выполняются параллельно
Mutation — для изменения данных (аналог POST/PUT/DELETE). Выполняются последовательно, чтобы избежать race conditions

4. Что такое "резолвер" (resolver) и кто его вызывает?

Функция, которая возвращает данные для конкретного поля. Вызывается сервером GraphQL при выполнении запроса

5. Как решается проблема N+1 запросов в GraphQL (dataloader)?

Dataloader группирует запросы и делает их одним батчем

6. Почему в GraphQL сложно реализовать кэширование на уровне HTTP (как в REST)?

В REST кэшируется каждый эндпоинт. В GraphQL:

    Все запросы идут на один URL

    Тела запросов разные (POST)

    Сложно кэшировать на уровне HTTP, используют кэширование на уровне клиента (Apollo Client, Relay)
