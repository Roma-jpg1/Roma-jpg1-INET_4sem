# Шаблон для отчетов

Данный проект представляет собой шаблон для оформления отчета (по курсовой работе, курсовому проекту и т.п.) по дисциплине (например, «Интернет-технологии и сетевое программное обеспечение») с использованием LaTeX в соответствии с ГОСТ и методическими указаниями СибГУТИ.

## Структура проекта
- `main.tex` — главный файл, который собирает весь документ воедино.
- `preamble.tex` — преамбула со всеми настройками пакетов, ГОСТ-отступов, стилей заголовков и библиографии.
- `titlepage.tex` — титульный лист (нужно заполнить свои данные).
- `chapters/` — папка с разделами документа (введение, основная часть, заключение).
- `biblio.bib` — файл для базы данных списка литературы.

## Компиляция
Для правильного отображения шрифтов (Times New Roman) и кириллицы проект **необходимо** компилировать с помощью `XeLaTeX`. Для обработки библиографии используется `Biber`.

### Порядок сборки (через терминал):
```bash
xelatex main.tex
biber main
xelatex main.tex
xelatex main.tex
```

Или, если у вас установлен `latexmk`:
```bash
latexmk -xelatex main.tex
```

## Настройка данных
Откройте файл `titlepage.tex` и замените текст в квадратных скобках (например, `[Название вашей темы]`, `[ФИО студента]`) на ваши реальные данные. Основной текст пишите в файлах в папке `chapters/`.
